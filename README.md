# Distance Calculator

## Description
A Python program that calculates the 2D Euclidean distance between two points using the `math` library.

## How to Run the Program
Run the program in any Python environment using:
python distance_calculator.py

## Input Needed
- x1, y1 (Coordinates for the first point)
- x2, y2 (Coordinates for the second point)

## Sample Output
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8
The distance between the two points is: 7.07
